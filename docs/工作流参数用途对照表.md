# 项目工具与工作流参数用途对照表

检查日期：2026-11-04。范围为项目当前 `tool_registry`、参数校验、参数换算、模板渲染与本机已安装节点源码。共10个工具、11个注册版本。以下为代码与模板检查结果，未提交生成任务；资源上限标注的是代码默认值，实际设置可覆盖。

阅读顺序：先看工具总表和入口参数，再看固定采样配置；需要精确定位时，文末逐版本列出全部节点输入。这里的“固定”表示当前应用没有该参数的单次执行入口，并不表示ComfyUI节点本身不允许修改。

## 2. 当前应用可填写的参数

所有工具都有 `seed`，均可留空随机。除SeedVR2允许0–4294967295外，其余允许0–9007199254740991。下表范围来自后端Schema与校验；界面步长只是输入控件设置，不总等于后端要求。

### 快速文生图（`image.generate.zimage`）

| 参数/输入槽 | 含义 | 默认 / 范围 | 用途与注意点 |
| --- | --- | --- | --- |
| `prompt` | 创作描述 | 空；必填 | 描述要生成的主体、环境、构图、动作、风格；视频还可描述声音。必填，1–12000字符。 |
| `negative_prompt` | 避免出现 | 空；可选 | 负条件文本，最多8000字符；当前CFG=0.8，不是常见CFG&gt;1的排除式引导，不能照搬“词越多越能排除”的理解。 |
| `width` | 宽度 | 1024；512–1536；32倍数 | 生成画布宽度，单位px；改变画幅、构图和资源开销。Qwen需16倍数，Z-Image需32倍数。 |
| `height` | 高度 | 1024；512–1536；32倍数 | 生成画布高度，单位px；与宽度共同决定比例和总像素。Qwen需16倍数，Z-Image需32倍数。 |
| `seed` | 随机种子 | 留空随机；0–9007199254740991 | 控制初始随机噪声。留空由后端生成并记录；文生图多候选使用起始种子、起始种子+1等。复现还需相同模型、图和其他参数。 |
| `candidate_count` | 候选数量（方案级） | 默认1；1–4 | 文生图候选串行执行，种子递增；编辑、放大和视频要求1。此字段不在manifest.fields中，但属于实际执行请求。 |

## 6. 检查发现的易误解点

| 位置 | 实际情况 | 理解参数时的影响 |
| --- | --- | --- |
| 快速分支的negative_prompt | 当前Qwen文生图fast、单图编辑、参考编辑1.1.0均CFG=1；本机comfy.samplers会跳过负条件采样；CFGNorm的post-CFG模式不取消该优化。 | 可填、可保存、有连线，不等于会产生负向CFG效果。应把关键保持/排除要求写进正向描述或编辑指令，并理解模型遵循能力的限制。 |
| Z-Image的negative_prompt | 当前CFG=0.8；标准组合为uncond + 0.8×(cond−uncond)。 | 不能当成常见CFG&gt;1的负提示词排除机制；不要凭界面名称判断实际作用。 |
| 参考编辑的尺寸 | API的ImageScaleToMaxDimension把最长边设到1280，包括放大小图；Registry预估却使用min(1,1280/最长边)且另做16对齐。 | 例如512×512输入，方案预估512×512，节点路径会走1280×1280。此处是静态代码发现，未用新生成任务验证。 |
| 视频0.6MP上限 | 0.6MP在16:9/9:16/1:1经32对齐后分别为642048/642048/640000像素。 | 都超过代码默认630000，即使参数Schema允许0.6，默认资源检查仍会拒绝。 |
| 视频source比例 | 宽高分别对齐32，最终比例不一定严格等于源图。首帧拉伸；尾帧采用居中裁剪。 | “跟随原图比例”是尺寸推导策略，不能理解成所有输入像素都原样进入画布。 |
| Qwen质量档尺寸 | 后端仅在请求未给宽高时补1328×1328；前端切换档位且原尺寸为1024方图或1328方图时也会切换尺寸。 | 自定义尺寸不必然被质量档覆盖；1328并非固定唯一输出尺寸。 |
| 原始UI widget和API执行图 | Qwen steps/cfg由开关连线提供；视频width/height由程序写入；原UI中未连接/静音分支不等于会执行。 | 判断有效值要看最终API图和选中分支。修改某个被连线覆盖的UI数字可能没有作用。 |
| UI randomize / fixed | 原始UI中的control_after_generate不进入API执行参数；当前应用在normalize阶段确定seed，多候选按seed+i执行。 | 模板样例seed、UI随机模式与实际执行seed需要区分。 |
| 导入脚本覆盖范围 | scripts/prepare_tools.py目前entries含6个工具，运行时Registry实际按manifest加载10个。 | 当前工具清单以注册目录和运行时代码为准，不能只按导入脚本推断。 |
