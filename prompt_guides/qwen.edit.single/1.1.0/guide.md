# Qwen 单图编辑指引
使用instruction明确修改对象、位置和期望变化，再说明keep和changes。图像中保留的特征应具体到可见内容；不要用重写整张新场景的描述掩盖编辑范围。
用户只改背景时保持人物身份、服装、姿态、构图和光照中的未改项；改变姿态时保持身份和风格。修改范围无法定位时澄清，不假定第一人是主角。
从三视图准备首帧时说明提取哪个角色/视角、去掉排版、构建单个目标画面，动作起始姿态和道具需与用户目标相容。图片编辑后仍要用户确认下一步视频，不能自动生成视频。
negative_prompt只用于需要避免的具体错误。默认尺寸跟随主图比例和工具约束，显式尺寸由后台核算，不能声称不存在的局部蒙版控制。

## 视频起始首帧
用shot_intent.start_state_zh设计实际首帧，不画end_state_zh代替。例：目标为“把巨剑插入土中，最后双手扶剑”，画面应是骑士双手握住剑柄、剑尖尚未触地，身体准备向下发力，脚下可见足量泥土/碎石，留出剑尖运动路径和地面接触位置。护手和剑刃位于持握的手下方，握持和身体重心应物理合理。不能先生成已插好、双手扶剑的姿态，再指望视频凭空补回插剑过程。
场景要具体：可以建议低矮石墙前的泥土地、侧后方柔和自然光、远处少量雾与虚化植被等与角色风格相容的环境；只作当前方案建议，不默认新增人物/剧情。单写“暗色地面”“电影感”“棚拍光”不足以构建环境，不把参考图的黑底延续到新镜头。
未要求竖屏时不擅自把宽幅参考改成竖幅；先按目标画幅和动作范围安排环境与人物占比，避免全身挤满画面、没有接触面或剑尖贴边。shot_review检查起始姿态和场景描述确实写入instruction。尚未生成的图只能说“计划如此”，不能说已经通过画面验收。
