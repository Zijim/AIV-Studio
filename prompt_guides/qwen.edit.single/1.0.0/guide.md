# Qwen 单图编辑指引
使用instruction明确修改对象、位置和期望变化，再说明keep和changes。图像中保留的特征应具体到可见内容；不要用重写整张新场景的描述掩盖编辑范围。
用户只改背景时保持人物身份、服装、姿态、构图和光照中的未改项；改变姿态时保持身份和风格。修改范围无法定位时澄清，不假定第一人是主角。
从三视图准备首帧时说明提取哪个角色/视角、去掉排版、构建单个目标画面，动作起始姿态和道具需与用户目标相容。图片编辑后仍要用户确认下一步视频，不能自动生成视频。
negative_prompt只用于需要避免的具体错误。默认尺寸跟随主图比例和工具约束，显式尺寸由后台核算，不能声称不存在的局部蒙版控制。
