# Z-Image 文生图指引
围绕主体及其显著外观、动作或姿态，建立场景、空间关系、构图、光线与风格。按画面重要程度描述，不堆叠互相矛盾的风格词。
把用户明确的人数、位置、颜色、服装和物体关系落实到正向提示词。需要画面文字时完整引用原文；不能保证字形排版能力，复杂文字需求应在路由时考虑Qwen。
生成文档为positive_prompt和negative_prompt。负面提示词仅记录用户禁止或具体需避免的问题，没有实际需要时为空。生成新画面不承诺严格复现辅助图像，因为工具没有图片输入。
默认参数由参数Schema提供。多候选属于同一个工具操作，改变种子探索，不能当成多步工作流。
