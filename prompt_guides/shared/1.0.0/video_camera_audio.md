# 视频共同写作方法
每个镜头描述当前构图、主体外观和位置、环境光线、动作及状态变化、镜头和当前可听声音。所有细节服务于用户目标；默认单镜头固定机位，不能为了丰富擅自切镜或推镜。
镜头运动用准确自然动作表达，区分 Zoom（焦距变化）、Push/Pull（机位前后）、Pan（水平旋转）、Truck（水平平移）、Tilt（竖直旋转）、Pedestal（机位升降）。需要时注明 small/large amplitude 和 slow/fast speed；没有运动时写 static shot，不同时要求移动。
动作分为起始状态、动作起势、连续中间变化、结果或反应。需要时写清持握、接触、重心、物体运动、惯性及结束保持。不要只复述剧情大纲，不把多个互不衔接的动作堆进短时长。
首镜index=1且cut_at_seconds=null；后续切镜时间严格递增，必须发生在最后一帧之前。无用户或已确认方案依据不新增切镜。编译器负责Shot标签和切镜时间，description不自行重复这些前缀。
物理动作发生时可写同步音效，overall_soundscape用1–4句概括环境声和非语言声音，不重复台词。完全静音时为N/A；没有对白仍可有自然声。默认自然动作声，不擅自添加配乐。
non_diegetic_music只描述观众听见、场中人物听不见的配乐。用户要求时用1–3句说明乐器、节拍、速度和渐强渐弱；无配乐为N/A。场中收音机等声音写在镜头正文，不能混为背景配乐。
真正说话/唱歌/旁白的人按首次发声顺序使用稳定(S1)、(S2)编号；无人发声不创建编号。原文写作<d>[Chinese]原文</d>等，保留每个字及标点，文案不能翻译。角色动作和声音特征放在<d>外。
旁白用says in an off-screen voiceover，并说明对应画面角色嘴唇闭合。对白跨切镜使用<scenetrans>并说明声音连续；结束被截断用<cutoff>。没有相应需求不添加这些事件。
画面文字用英文双引号括住原文，不翻译。参考资料中的例句不是用户台词。
